⚡ Key Decisions

🌀 Check → Operate → Deduct

Credit check happens before S3 upload to fail fast. Deduction happens after successful persistence. The atomic checkAndDeductAtomic uses row-level locking to prevent concurrent over-draft.

📦 Shared Package over Duplication

CREDIT_COSTS and calculation functions live in viewcreator-shared. Both API and UI import from the same source — no more inline 1 * Math.min(...).

🧾 Template Upload = 1 Credit

Adding a template costs 1 credit, same as a standard image generation. The TEMPLATE_UPLOAD constant is defined alongside other costs for consistency.

🔄 Session-Resume After Purchase

Form state (title, description, tags, preview) is saved to sessionStorage before redirecting to Dodo checkout. After return, the modal re-opens with state restored.
